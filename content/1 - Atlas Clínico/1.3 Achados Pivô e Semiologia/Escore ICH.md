# Escore ICH (Intracerebral Hemorrhage Score)

> [!abstract] O que é?
> Escala prognóstica que estima **mortalidade em 30 dias** após [[Hemorragia Intraparenquimatosa]] — pontuação de 0-6 baseada em parâmetros clínicos (Glasgow, idade) e radiológicos (volume, localização, hemoventrículo), auxiliando na decisão entre tratamento conservador e cirúrgico.

## 🖐️ Técnica de Exame (Como fazer?)

1. **Aplicação:** Após TC inicial diagnóstica de AVC hemorrágico, somar os pontos dos 5 itens

### **Itens do Escore ICH**

| Item | Critério | Pontos |
|---|---|---|
| **Glasgow (GCS)** | 13-15 | 0 |
| | 5-12 | 1 |
| | 3-4 | **2** |
| **Volume do hematoma** | < 30 mL | 0 |
| | ≥ 30 mL | 1 |
| **Hemoventrículo** | Não | 0 |
| | Sim | 1 |
| **Localização** | Supratentorial | 0 |
| | **Infratentorial** | 1 |
| **Idade** | < 80 anos | 0 |
| | ≥ 80 anos | 1 |

**Total: 0-6 pontos**

## 🌪️ Mecanismo Fisiopatológico

- Cada item refletindo um fator que afeta o prognóstico:
	- **Glasgow baixo:** maior compromisso neurológico
	- **Volume ≥30 mL:** mais lesão tecidual e mais efeito de massa
	- **Hemoventrículo:** risco de hidrocefalia obstrutiva e disseminação
	- **Infratentorial:** menor espaço para edema, herniação tonsilar mais rápida
	- **Idade ≥80:** menor reserva neurológica e maior comorbidade

---

## 🎯 PODER DIAGNÓSTICO (O PIVÔ)

### **Mortalidade em 30 dias**

| Score | Mortalidade em 30 dias |
|---|---|
| **0** | 0% |
| **1** | 13% |
| **2** | 26% |
| **3** | 72% |
| **4** | 97% |
| **5** | 100% |
| **6** | 100% |

### **Pivôs de Decisão Terapêutica**

- **ICH 0-3** → geralmente abordagem cirúrgica pode ser considerada se outros critérios presentes
- **ICH 4-6** → geralmente **não opera** (mortalidade muito elevada apesar da intervenção)
- Decisão sempre **individualizada** — escore é guia, não regra absoluta

### **Como Calcular o Volume do Hematoma — Método ABC/2**

- Aproximação rápida para estimar o volume:
- **V = (A × B × C) / 2** (em mL)
	- **A** = maior diâmetro do hematoma na TC (cm)
	- **B** = diâmetro perpendicular ao A no mesmo corte (cm)
	- **C** = número de cortes onde o hematoma é visível × espessura do corte (cm)

---

## ⚠️ Pitfalls e Falsos

- **Não considera coagulopatia** (uso de anticoagulantes) — pacientes anticoagulados têm pior prognóstico
- **Não considera expansão do hematoma** nas primeiras horas — fator dinâmico importante
- O método ABC/2 **superestima volume** em hematomas irregulares ou multilobulados
- Decisão cirúrgica deve sempre considerar **fatores clínicos individuais** (status pré-AVC, comorbidades)
