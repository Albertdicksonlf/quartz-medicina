# Toxoplasmose Congênita

> [!abstract] Definição
> Transmissão vertical do parasita quando a mãe adquire a **Primoinfecção Aguda durante a gestação**.
> **Regra de Ouro:** Quanto mais cedo a infecção na gravidez, **MENOR** o risco de transmissão, mas **MAIOR** a gravidade das sequelas fetais.

## 1. Quadro Clínico (Feto/RN)
- **Tríade de Sabin (Clássica):**
    1.  **[[Coriorretinite]]** (Bilateral, causa cegueira).
    2.  **[[Hidrocefalia]]**.
    3.  **[[Calcificações Intracranianas]]** (Difusas).
- **Outros:** Microcefalia, Hepatoesplenomegalia, Surdez, Retardo mental.
- A maioria nasce assintomática, mas desenvolve sequelas (oculares) tardiamente se não tratada.



## 2. Rastreio Pré-Natal (Interpretação)
*Solicitar IgG e IgM no 1º trimestre.*

| Resultado             | Interpretação     | Conduta                                                                                             |
| :-------------------- | :---------------- | :-------------------------------------------------------------------------------------------------- |
| **IgG (-) / IgM (-)** | Suscetível        | Orientar higiene (não comer carne crua, cuidado com gato). Repetir mensal/trimestral.               |
| **IgG (+) / IgM (-)** | Imune (Antiga)    | Não há risco para o feto (exceto se imunossupressão grave materna).                                 |
| **IgG (-) / IgM (+)** | Infecção Aguda?   | Iniciar **Espiramicina** imediatamente e repetir sorologia em 2 semanas (ver se IgG vira positivo). |
| **IgG (+) / IgM (+)** | Infecção Recente? | Solicitar **[[Teste de Avidez de IgG]]** (se < 16 semanas).                                         |
|                       |                   |                                                                                                     |

### **Teste de Avidez (O Desempate)**
- **Alta Avidez (> 60%):** Infecção antiga (> 4 meses). **Risco fetal ZERO**. Suspende tratamento.
- **Baixa Avidez (< 30%):** Infecção recente (< 4 meses). **Alto Risco**. Mantém tratamento e investiga feto.

## 3. Investigação Fetal
- Se confirmada infecção aguda materna: Realizar **Amniocentese** (PCR no Líquido Amniótico) a partir de 18 semanas.

---
## 🎯 ACHADOS PIVÔ
- **Ultrassom Fetal:** [[Calcificações cerebrais difusas]], [[Ventriculomegalia]].
- **Fundo de Olho:** [[Lesão em "Roda de Carroça" (Coriorretinite)]].
- **Laboratório:** [[IgM positivo na gestante com Baixa Avidez]].

---
## 💊 Tratamento

### **A. Na Gestante**
1.  **Sem confirmação fetal (Profilaxia):** **[[Espiramicina]]**. (Macrolídeo que não atravessa bem a placenta, mas concentra nela e impede a passagem do parasita).
2.  **Com confirmação fetal (PCR+ ou USG alterado):** Alternar para **Esquema Tríplice** (**[[Sulfadiazina]] + [[Pirimetamina]] + [[Ácido Folínico]]**).
    - *Atenção:* Pirimetamina é teratogênica no 1º trimestre (só usar após 18-20 semanas).

### **B. No Recém-Nascido (Congênita)**
- Todos os confirmados ou altamente suspeitos.
- Esquema: **Sulfadiazina + Pirimetamina + Ácido Folínico** por **12 meses**.
- Corticoide: Adicionar se houver proteína alta no líquor ou coriorretinite ativa (para desinflamar).
