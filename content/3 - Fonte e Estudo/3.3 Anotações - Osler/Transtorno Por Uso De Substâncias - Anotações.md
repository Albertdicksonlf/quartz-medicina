# Transtorno Por Uso De Substâncias - Anotações

*Documento PDF original do usuário, processado em 2026-05-02 sem aula prévia no vault. Conteúdo cobrindo álcool, opioides, cocaína/crack e nicotina, com conceitos integradores de drogas depressoras × estimulantes × perturbadoras.*

## Resumo dos Conceitos do PDF

### Conceitos Gerais
- Drogas depressoras (álcool, opioides) → cérebro adapta-se elevado → abstinência simpática
- Drogas estimulantes (cocaína, anfetamina, nicotina) → cérebro adapta-se rebaixado → abstinência depressiva
- Drogas perturbadoras (maconha, LSD) → alteram percepção, abstinência leve

### Princípios Integradores
- **Abstinência = oposto do efeito da droga**
- **Tolerância** = doses crescentes para mesmo efeito
- **Reforço positivo** (efeito agradável) e **reforço negativo** (alívio da abstinência)

### Álcool
- Intoxicação progressiva: euforia → ataxia → coma
- CAGE para triagem (≥ 2 = positivo)
- Tratamento: Naltrexona, Acamprosato, Dissulfiram, Topiramato
- Abstinência: tremor 6h → alucinose 12h → convulsões 24h → DT 48-96h
- Tratamento abstinência: BZD + tiamina + suporte
- Complicações: Cirrose, IC (Beribéri), Wernicke-Korsakoff

### Opioides
- Intoxicação: tríade miose + bradipneia + rebaixamento
- Tratamento overdose: Naloxona + suporte respiratório
- Manutenção: Metadona, Buprenorfina, Naltrexona

### Cocaína/Crack
- Intoxicação: hiperatividade simpática + midríase
- Tratamento: BZD, Fentolamina; NUNCA β-bloqueador isolado
- Abstinência: depressão, fadiga, fissura (sem risco vital)

### Nicotina
- Fagerström para classificação (≥ 5 = intervenção)
- Primeira linha: TRN (adesivo + goma/pastilha SOS)
- Bupropiona (combinável com TRN)
- Vareniclina (não SUS)
- Nortriptilina, Clonidina (segunda linha)
